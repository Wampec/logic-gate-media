# logic-gate-media

Dočasné úložiště videí pro [The Logic Gate](https://fokusso.com/thelogicgate).

Repozitář je veřejný z jediného důvodu: **Instagram nepřijímá nahrání
souboru.** Video si stahuje sám z adresy, kterou mu pošlete, takže musí
být veřejně dostupné. Obrázky tenhle problém nemají — ty se nahrávají
přes Facebook.

Leží tu vždy jen videa aktuálního týdne a každý pátek se obsah přepíše.
Nic tu není dřív, než to vyjde na YouTube.

Veškerý kód, který s tímhle repozitářem pracuje, je jinde a je soukromý.
